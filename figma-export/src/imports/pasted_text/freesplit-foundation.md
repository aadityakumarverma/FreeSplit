==================================================
DARK MODE
==================================================

Dark Mode is the PRIMARY visual identity.

It should feel like a refined JARVIS command center:

- near-black navy
- cyan energy accents
- green financial indicators
- purple intelligence indicators
- thin illuminated borders
- subtle glow
- technical typography
- data visualization

Avoid excessive neon.

Avoid excessive glassmorphism.

Avoid excessive rounded cards.

The result should feel engineered and premium.

==================================================
LIGHT MODE
==================================================

Create a proper Light Mode variant.

Do NOT simply invert Dark Mode.

Light Mode should feel like:

"JARVIS in daylight."

Use:
- white/light-blue surfaces
- subtle cyan borders
- purple highlights
- green status indicators
- soft shadows
- extremely subtle grid

Keep the same brand identity and component structure.
